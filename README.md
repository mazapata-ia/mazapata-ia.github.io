# Ofrenda · Mariana Zapata

Un espacio para pensar, sentir y escribir.

Sitio: https://mazapata-ia.github.io/

## Cómo se actualiza

- Los escritos viven en `_fuente/escritos.json` (texto exacto, sin correcciones).
- `python3 _fuente/generar.py` regenera todas las páginas, el índice y `sitemap.xml`.
- Las páginas generadas (`index.html`, `breves/`, `largos/`, `lecturas/`, `escritos/`, `acerca/`, `apoyar/`) no se editan a mano.
